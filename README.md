A tiny Node 22 program that writes a single funny one-line resignation letter to `entry.txt`: a zookeeper quits because the penguins have unionized and negotiated a better contract than he ever did. Run it with `node main.ts` (it reads `MAKEFUN_OUTPUT_DIR`, defaulting to `/output`) and it produces exactly one line of 1–140 characters, ready for the judge.

## Run

```sh
node main.ts
```
